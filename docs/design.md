# Семестр — архитектура и дизайн-система

Рабочий конкурсный прототип цифрового деканата для вымышленных студентов и методиста учебного офиса. Название, корпуса А/Б/В, профили и события придуманы для демонстрации.

## Визуальная система

Интерфейс построен на принципах спокойной функциональной чистоты (ориентиры — GNOME Adwaita и веб-продукт Revolut) с отказом от визуального шума:

- **Токены на `oklch` и строгая тёмная тема**:
  - Светлая тема: спокойный известняково-хвойный холст (`oklch(.97 .004 155)`), плоские белые поверхности (`--card`) с тонкими границами `1px` и сдержанный глубокий лесной акцент (`oklch(.265 .042 160)`).
  - Тёмная тема: чистая монохромная лестница светлоты `oklch` (`--bg: oklch(.17 0 0)`, `--card: oklch(.22 0 0)`, `--card-2: oklch(.26 0 0)`, `--line: oklch(.29 0 0)`, `--text: oklch(.94 0 0)`) с зеркальной инверсией акцента (`--accent: oklch(.95 0 0)` на `--on-accent: oklch(.18 0 0)`). Тёмная тема объявлена дважды (`@media (prefers-color-scheme: dark)` и `[data-theme=dark]`) и синхронизируется с cookie без вспышки при перезагрузке.
  - Цвет в обеих темах зарезервирован исключительно для семантических статусов (`--ok`, `--warn`, `--err`) и тонких контурных рамок `.state` без залитых пастельных капсул.
- **Типографика**: геометрический гротеск `Adwaita Sans` Variable без декоративных ALL-CAPS надзаголовков и моноширинный `JetBrains Mono` Variable (`tabular-nums`) для времени пар, кодов аудиторий, 100-балльного рейтинга, ЗЕТ и реестровых номеров.
- **Компоненты и микровзаимодействия**: списки `boxed-list` с тонкими разделителями `1px`, сегментированные переключатели `.seg` с единой скользящей скруглённой квадратной подложкой `.seg-thumb` (`cubic-bezier(.22, 1, .36, 1)`), лаконичные кнопки-иконки `.icon-btn` с поворотом лучей солнца на 45° и единая архитектурная фотография модернистского корпуса только на экране входа `/login`.

## Ключевые контуры

1. **Учебный день (Главная)**: фокус-карточка текущей или ближайшей пары с корпусом, этажом и маршрутом перехода, блок изменений и сроков, таймлайн пар с расчётом окон, последние заявки и сводка семестра.
2. **Расписание и экспорт `.ics`**: режимы «Сегодня» и «Неделя» (многоколоночная матрица на десктопе и адаптивная повестка на `360px`), индикация переносов аудиторий и выгрузка недели в формате RFC 5545 (`/schedule.ics`).
3. **Успеваемость**: сводная полоса семестра, 100-балльный рейтинг (`ECTS`), учёт `ЗЕТ`, сегментированный фильтр дисциплин и расписание сессии.
4. **Заявки и электронные бланки**: идемпотентная подача заявок с отсчётом готовности и печатный бланк справки с матричным QR-кодом и реестровым номером.
5. **Кабинет сотрудника деканата (`/staff`)**: отдельный ролевой контур методиста учебного офиса (`dean@demo.example`) с очередью студенческих заявок, официальным ответом по заявлениям и публикацией групповых уведомлений.
6. **Безопасность**: Flask + SQLite (WAL), `scrypt`-хеширование паролей, серверный отзыв сессий, CSRF-защита, строгий `Content-Security-Policy: default-src 'self'` (ноль inline-стилей и скриптов) и проверка владельца/роли на каждом запросе.
