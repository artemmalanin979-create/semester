# Семестр

Рабочий конкурсный прототип цифрового деканата для вымышленных студентов. Название, учебный корпус, профили и события придуманы для демонстрации.

Сценарий «Что у меня дальше?» связывает ближайшее занятие, переносы, учебные дедлайны и состояние заявок. Главное действие в контексте ведёт в расписание, заявку или уведомление. Расписание открывается в режимах «Сегодня» и «Неделя». Успеваемость включает оценки, зачёты и даты сессии. Центр уведомлений хранит состояние чтения.

## Подход

Одна серверная веб-служба на Flask с HTML-шаблонами и SQLite. Обычные ссылки и формы работают без JavaScript. Это упрощает запуск на VPS, а SQLite на постоянном томе хранит заявки между перезапусками. Рассматривались SPA с отдельным API и внешняя база. Их можно подключить по мере появления отдельных клиентских приложений и необходимости нескольких экземпляров базы.

Визуальный центр главной — карточка ближайшей пары на фоне иллюстрации кампуса. Дальше последовательность дня и небольшая колонка с переносами и заявками. Цвета: глубокий сине-зелёный #15382f, акцент #c8f478, фон #f4f6f2, текст #172620, линии #e0e6dd, фон переносов #f7ebd8. Inter для основного текста, Inter Display для заголовков, табличные цифры для времени. На телефоне навигация закреплена снизу.

На сервере используются scrypt-хеши тестовых паролей, сессии с отзывом при выходе, CSRF-токены и фильтрация данных по текущему студенту. Симуляция обработки явно помечена, срок и следующий шаг видны на странице заявки. Служебный ключ передаётся через переменную окружения, HTTPS завершает прокси.
