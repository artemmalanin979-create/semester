# План реализации «Семестр»

1. Проверить вход, выход, CSRF, попытки прочитать чужую заявку и состояние базы после запуска нового экземпляра. Сохранить поведенческие тесты в tests/.
2. Реализовать схему, демонстрационные группы и профили, сессии и маршруты ядра в semester/. Оформить заявки как идемпотентные POST и страницы отслеживания.
3. Собрать страницы Flask/Jinja, связать главную с расписанием, уведомлениями и заявками. Проверить маршрут студента в браузере при 360 px и на настольном экране. Сохранить скриншоты принятых решений и поправок.
4. Подготовить контейнер с постоянным томом, README, архив исходников и PDF процесса. Публичный URL и проверка из РФ требуют публикации на согласованном хостинге. Отправку через форму выполняет капитан.
