# Семестр

- Используй только синтетические данные. Названия и иллюстрации не должны выдавать прототип за систему вуза.
- Идентификатор студента получает сервер через сессию. Запросы к приватным записям всегда ограничивай этим идентификатором.
- Для POST проверь CSRF и удерживай состояние в SQLite. При изменении заявок проверь повторную и параллельную отправку.
- Пройди основной маршрут на 360 px. Сохрани доступность форм, фокуса и ссылок без JavaScript.
- Проверки запускаются командой `python -m unittest discover -s tests -v`. Правила запуска и аккаунты описаны в README.
